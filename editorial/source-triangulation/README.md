# Source Triangulation Workspace

This directory is the durable working area for Morning Edition's multi-source verification and perspective practice.

The authoritative rules live in the repository root at:

- `SOURCE_TRIANGULATION_PROTOCOL.md`

Use this directory for material that helps improve that protocol without bloating the main editorial guide, including:

- examples of strong local/primary + external-verifier pairings;
- difficult cases where apparently separate outlets share one underlying information source;
- notes on state-controlled, partisan, institutional, or ownership-sensitive sources;
- recurring source ecosystems by country or region;
- examples of useful disagreement handling;
- examples of false balance to avoid;
- source-role conventions for `supporting_sources` in reader packs;
- future audits of whether Continue Reading is actually improving perspective rather than merely adding links.

Do not store daily published reader packs here. Published synthesis remains in `data/readers/YYYY-MM-DD.json` and the normal edition archive.
